# Alpenglow 实机测试笔记

## 26-11-15 Sun. 秋假第二天
> 今日正式建立此文件，用于记录闲暇时刻发现的 Alpenglow 实机小漏洞。

### 随记
1. `all` 的表格式不统一：
  ```
  [0]root@alpenglow:~ # all wifi list
  ID  SSID         BSSID  FLAGS       PRIORITY
  0   FAST_XQL     any    [DISABLED]  8
  1   FAST_XQL2    any    [DISABLED]  9
  2   FAST_XQL_5G  any    [CURRENT]   10
  ```

  ```
  [0]root@alpenglow:~ # all wifi scan
  bssid              frequency  signal level  flags                                              ssid
  44:df:65:e2:37:85  5745       -52           [WPA-PSK-CCMP+TKIP][WPA2-PSK-CCMP+TKIP][WPS][ESS]  FAST_XQL_5G
  44:df:65:e2:37:86  2442       -41           [WPA-PSK-CCMP+TKIP][WPA2-PSK-CCMP+TKIP][WPS][ESS]  FAST_XQL
  c4:64:b7:7a:8f:dd  2437       -56           [WPA-PSK-CCMP+TKIP][WPA2-PSK-CCMP+TKIP][WPS][ESS]  FAST_XQL2
  34:ca:81:84:1b:9a  2462       -76           [WPA2-PSK-CCMP][WPS][ESS]                          401
  3a:ca:81:84:1b:9a  2462       -77           [WPA2-PSK-CCMP][ESS]                               
  34:ca:81:84:1b:9b  5300       -84           [WPA2-PSK-CCMP][WPS][ESS]                          401-5G
  30:19:84:c9:28:b4  2412       -74           [WPA2-PSK-CCMP][WPS][ESS]                          601
  3a:ca:81:84:1b:9b  5300       -83           [WPA2-PSK-CCMP][ESS]
  ```

可以注意到，`all wifi list` 表头是 **大写** ，而 `all wifi scan` 的却是 **小写** 。应该统一为 **大写** 更符合逻辑。

2. PS1 的最后一个字符（ `#` / `$` ）颜色不明显。

3. `all pkg` 命令根本上是调用 `apk` ，并且还要多输入几个字符，毫无用处。

4. `all reboot` 和 `all poweroff` 也完全没有存在的理由

5. 所有带子菜单的项最好都弄得像 `all wifi` 那样完整，比如：
  ```
  usage: all gpio list|func <pin>|set <pin>/<func>|get <chip> <line>|put <chip> <line> <0|1>|wiringx
  ```
这种用户根本分辨不清。

6. `all wifi` 的交互模式其实并没有实现。

7. `all wifi status` 与 `all net` 功能严重重合：
  ```
  [1]root@alpenglow:~ # all wifi status
  bssid=44:df:65:e2:37:85
  freq=5745
  ssid=FAST_XQL_5G
  id=2
  mode=station
  wifi_generation=6
  pairwise_cipher=CCMP
  group_cipher=TKIP
  key_mgmt=WPA2-PSK
  wpa_state=COMPLETED
  ip_address=192.168.31.252
  p2p_device_address=88:00:33:77:4f:51
  address=88:00:33:77:4f:50
  uuid=0c522858-dbe9-550c-97f2-d37e1943cdcc
  ieee80211ac=1

  4: wlan0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP qlen 1000
      link/ether 88:00:33:77:4f:50 brd ff:ff:ff:ff:ff:ff
      inet 192.168.31.252/24 brd 192.168.31.255 scope global dynamic noprefixroute wlan0
        valid_lft 38426sec preferred_lft 33026sec
      inet6 fe80::8a00:33ff:fe77:4f50/64 scope link 
        valid_lft forever preferred_lft forever
  ```

  ```
  [0]root@alpenglow:~ # all net
  == interfaces ==
  ip not available

  == ipv4 routes ==
  default via 192.168.31.1 dev wlan0  src 192.168.31.252  metric 3004 
  192.168.31.0/24 dev wlan0 scope link  src 192.168.31.252  metric 3004 
  192.168.42.0/24 dev usb0 scope link  src 192.168.42.1 

  == ipv6 routes ==
  local ::1 dev lo  metric 0 
  local fe80::84b1:c6ff:fe0f:e317 dev usb0  metric 0 
  local fe80::8a00:33ff:fe77:4f50 dev wlan0  metric 0 
  fe80::/64 dev wlan0  metric 256 
  fe80::/64 dev usb0  metric 256 
  ff00::/8 dev wlan0  metric 256 
  ff00::/8 dev usb0  metric 256 

  == resolv.conf ==
  # Generated by dhcpcd from wlan0.dhcp
  nameserver 119.29.29.29
  nameserver 192.168.31.1
  # /etc/resolv.conf.tail can replace this line
  ```

前者应保留必要的内容（包括IP地址），后者亦然，但目前未定断如何改良。
此外还应该将大部分命令输出加以格式化，比如所有 `ip` 命令的，这样能够更好地凸显 `all` 的作用。
