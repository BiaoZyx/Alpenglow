# Alpenglow

Alpine Linux on Milk-V Duo S (SG2000, ARM64, musl), running on the
Milk-V duo-buildroot-sdk-v2 kernel and device tree.

Status: v1.0.0 in development.

## Quick start

```
./build.sh --board duos
```

See `config/boards/duos.conf` for board-specific parameters.
